# One Control Plane

Mahsumah Cloud is being built around a simple principle:

> **Customers should manage products — not fragmented infrastructure.**

```text
┌──────────────────────────────────────────────────────┐
│                    CUSTOMER                          │
│                                                      │
│      Applications • APIs • SaaS • AI • Systems      │
└─────────────────────────┬────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────┐
│               MAHSUMAH CONTROL PLANE                 │
│                                                      │
│  Deployments    Domains & DNS    SSL                 │
│  Monitoring     Backups          Environments        │
│  Secrets        CI/CD            Operations          │
└─────────────────────────┬────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────┐
│               INFRASTRUCTURE LAYER                   │
│                                                      │
│  Compute       Containers       Storage              │
│  Networking    Security         Observability        │
│  AI Compute    Backup Systems   Delivery             │
└─────────────────────────┬────────────────────────────┘
                          │
                          ▼
                 Saudi Infrastructure 🇸🇦
```
